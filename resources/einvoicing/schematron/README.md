# Schematron rules

Official ZATCA Schematron files ship with the ZATCA Compliance and Enablement
Toolbox SDK. They are not copied from GitHub and are not redistributed here.

Set `E_INVOICE_SCHEMATRON_PATH` to a locally supplied official rules file in
deployment or CI when those artifacts are licensed for that environment.

`local-structure.sch` is a HASEM-owned structural smoke rule used to prove the
validator infrastructure. It is not a ZATCA compliance Schematron.
